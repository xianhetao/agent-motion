# 工程管线实测经验

本文件沉淀在真实工程（Apple Silicon、中国网络、Three.js 逐帧渲染）中验证过的环境与管线经验。它不改变设计规则，只解决"规则知道了却做不出来"的工程层问题。涉及本机路径、镜像与代理时以当前机器实测为准，换机器先验证再沿用。搭建渲染管线、准备本机环境或编排批量渲染前完整读取本文件；已在本工程验证过的配置直接复用，不重复踩坑。

## 环境与依赖安装

- Node 原生 fetch 不读 `HTTPS_PROXY` 环境变量；需要代理的脚本（bootstrap、下载器）用 undici `ProxyAgent` 做 shim 注入 dispatcher，而不是指望环境变量生效。
- Playwright Chromium 下载慢或卡死时设 `PLAYWRIGHT_DOWNLOAD_HOST=npmmirror`；Python 包走清华源。安装前先确认代理端口可用，不要在 20 分钟无输出的下载上等待。
- Node 运行时用受管版本并写绝对路径（本机 `~/.workbuddy/binaries/node/versions/22.22.2-6/bin/node`）；系统 nvm 版本可能被清理，脚本不依赖裸 `node`。
- 含中文文件名的 zip 解压乱码时，按 cp437 读名字再依次尝试 utf-8/gbk 解码重命名后解包；不要直接接受乱码路径进管线。
- pip 安装慢先换清华源；venv 装在受管 runtime 目录内，不污染全局。

## 渲染管线与确定性

- 完整成片用"本地静态 server + 无头 Chromium 逐帧截图 + ffmpeg 编码"渲染；不依赖实时播放录制，帧号即真相。
- 页面暴露 `window.film` 契约：`ready`（字体/纹理全部加载完成）、`duration`、`fps`、`renderAt(t)`（跳到绝对时间并稳定）、`pickAt(t)`（拾取该时刻对象）。渲染器只信任契约，不解析页面内部状态。
- 相机参数一次性标定后写入常量：竖版 720×1280 设计像素在相机 `z=1600`、`fov 43.60°` 时恰好铺满 `z=0` 平面；此后所有舞台元素直接用设计像素坐标，不再换算。
- 动态视频纹理会破坏逐帧确定性；人物层用图程序列（每帧一张 PNG，按帧号寻址）而不是 `<video>` 纹理。需要"框内人物二次居中"时，离线计算每帧头顶/质心锚点（±8 帧平滑），渲染时按锚点平移人物卡，而不是运行时分析。
- 锚点/取景数据从 alpha 序列流式计算，不要把全部帧载入内存；N 以万计时硬编码样本数会漏帧或被系统杀进程。
- 长片分语义段推进：先做通第一个语义单元到第二个单元的完整交接（样段），人工确认后再逐段扩展；每段渲染 3-5 个检查点静帧自查（进出点、遮挡关系、文字可读），不要整片盲渲到最后一刻。

## 人物层与取景实现

- 抠像用 RVM（ONNX CPU 推理约 0.14 秒/帧）；输出前景与 alpha 双轨，alpha 供取景计算，前景供合成。
- 竖版人物卡比例约 0.882（11:16）而不是 4:5——真人立姿头顶到手的纵向跨度常超出 4:5 卡片；比例按素材实测最大人形高度定，不按习惯值定。
- 人物卡二次取景锚定脸部而不是头顶：小窗时头顶锚定会让脸沉到卡底。
- 烧录字幕/文字与人物层同屏时，给取景窗设底部硬限，防止文字压身区域被抠像算法带进前景；人物层不含字幕时可放宽。
- 保留人物原背景时禁止描边；替换背景才描边。缩成小窗不改变这个判断。

## 实现陷阱清单

- 常驻网格需要按节奏显隐时，把可见性乘上 alpha（材质 opacity 与 visible 同步控制），不要只在创建时设一次 visible。
- 同一区域多张卡片叠放时显式排 z（逐张 +1 递增），被接管的卡片主动退后并降透明度；依赖默认插入顺序会被后建对象挡住。
- canvas 纹理先算好所有坐标（含行高、总高）再落笔；坐标公式改动后同步核验画布尺寸，越界绘制静默裁切、无报错。
- grep/rg 对 ▸ ✓ ✦ 等特殊字符可能静默无匹配；批量改源码用 python/node 脚本按精确子串替换，改完 diff 验证替换次数。
- 跨模块传递舞台上下文（相机、阴影、卡片、片段、人物）用显式对象一次性传入；新模块里引用外层变量前确认它在自己的作用域里真实存在，作用域错误在渲染时才暴露。

## 音效合成与重混

- 无素材音效用 numpy 直接合成，分三层：动作声（跟随对象运动）、提示声（跟随文字/信息揭示）、强重音（段落级）。事件表集中一处，从语义时间线生成。
- 增益、衰减、音色参数集中在合成脚本顶部常量区；改听感只改常量重跑混音（秒级），不动画面。
- 混音完成检查真峰值（≤ -1 dBTP 量级），不只看采样削波。
